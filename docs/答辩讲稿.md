# 作业讲解稿：我怎么把这个东西讲明白

> 用法：上课被问到时，按"一句话 → 30秒 → 3分钟"逐层展开，不要一上来就讲技术。
> 核心心法：**把技术名词全部换成人话，先讲"这东西替我干了什么"，再讲"它怎么做到的"。**

---

## 一、一句话版本（电梯里遇到老师）

> "我做了个**自动财经情报助手**：每天早上八点，它自己上网看新闻、让 AI 写成分好类、带影响分析的日报，然后发到我微信上。我全程不用管。"

关键词：**自动、每天、AI 分析、发到微信**。四个词讲完，老师就知道你干了什么。

---

## 二、30 秒版本（老师问"怎么做的"）

> "分三段：
> **第一段——闹钟。** 我在 GitHub 上设了个定时任务，每天早八点自动启动。
> **第二段——采购员。** 程序去新浪财经、东方财富、金十数据这几个免费接口，把过去一天的财经快讯全抓下来，大概两百多条，然后去重、筛掉旧闻。
> **第三段——编辑 + 邮差。** 把这些新闻丢给阿里云的大模型，让它按我定的要求写成日报——聚焦芯片、光通信、存储、AI 和先进封装，每条都要写"对我关注的板块有什么影响"；写完通过 Server酱 推到我微信。
> 整个跑在 GitHub 的服务器上，我电脑关着也照发。"

---

## 三、3 分钟版本（答辩 / 老师追问细节）

### 1. 我为什么要做这个
《公司金融》要求用 AI 做财经新闻汇总推送。但我发现**现成的财经 App 给的是"信息流"，不是"分析"**——它把两百条新闻堆给你，还得自己判断哪条跟我有关。我想要的是：**只讲我关心的赛道，并且直接告诉我"影响是什么"**。

### 2. 我把它拆成了四个零件
| 零件 | 干什么 | 我用什么做的 |
|---|---|---|
| ⏰ 闹钟 | 每天准时叫醒 | GitHub Actions 定时任务 |
| 🛒 采购员 | 去各处收新闻 | Python 抓 6 个公开财经接口 |
| ✍️ 编辑 | 筛选 + 写分析 | 阿里云百炼大模型（qwen3.7-max） |
| 🚚 邮差 | 送到我手上 | Server酱 → 微信服务号 |

**为什么用 GitHub？** 因为它自带两样东西：**免费的定时器 + 免费的服务器**。公共仓库的自动任务是无限免费的，而且每次运行都有绿色日志，**等于自带一份"我真的跑了"的证据**。

### 3. AI 在里面到底干了什么（这是老师最想听的）
AI 不是用来聊天的，它干的是**编辑的活**：
- 从 200 条里挑出跟芯片/光通信/存储/AI/先进封装相关的 20 条
- 每条压缩成一句话，再补一句**影响分析**（利好谁、利空谁、怎么传导）
- 宏观大事单独成栏，还要判断对科技板块的方向

比如今天它写出来的这条：
> **美国中期选举民主党拿下两院** → 国会分裂 → 极端对华科技管制法案更难通过 → 对芯片/AI 板块偏利多

这条不是我告诉它的，是它从新闻里自己读出来并串起逻辑的。

### 4. 我怎么保证它不乱说
- 提示词里明确写了：**严禁编造快讯里没有的数字和公司**
- 每天的日报都会**自动存档回仓库**，原文和成稿都在，可以回头核对
- 如果 AI 调用失败，程序会自动退回"关键词分类版"，不会空推送

## 四、老师可能追问的 8 个问题（背这几个就够）

**Q1：这算 AI 做的还是你做的？**
> 分工是：AI 帮我写代码、当每天的编辑；我定方向、定选题标准、验收结果。就像我用 Excel 算财务模型——工具是我的，判断也是我的。

**Q2：新闻哪来的？靠谱吗？**
> 六个公开接口：新浪财经、东方财富、金十数据。都是公开可访问的，不用付费。多源设计是为了互补——某个源挂了，其他源照样能出日报（程序里做了容错）。

**Q3：这不就是 RSS 订阅吗？**
> RSS 只负责"给你标题"。我做的是**二次加工**：跨源去重、按赛道筛选、加影响分析、还做了重要度分级。成品是"观点"，不是"列表"。

**Q4：会不会侵犯版权 / 违规？**
> 只抓公开接口、不绕过任何限制、报告里标明来源；只用于个人学习，不商用、不二次分发。

**Q5：花了多少钱？**
> GitHub 公共仓库的自动任务免费；大模型一次日报消耗约 1 万 token，用的是学校/阿里云提供的额度。基本零成本。

**Q6：怎么证明它是真的自动跑，不是你手动发的？**
> 打开 GitHub 的 Actions 页面，能看到带时间戳的运行记录和绿色对勾，还有机器人每天自动提交的存档文件。这是平台生成的，改不了。

**Q7：有什么局限？**
> 三个：① 依赖公开接口，接口变了要改；② AI 偶尔会误判重要性；③ 目前是"日频"，还没做语义级的历史检索。这些是我下一步想补的。

**Q8：如果让你继续做，下一步做什么？**
> ① 加"周报/月报"：把一周的日报再喂给 AI 做复盘；② 加自选股跟踪；③ 把推送扩展到企业微信群，让同学一起订阅。

---

## 五、现场演示三步（30 秒搞定）

1. **打开仓库首页** → 指着 `reports/` 说："这是每天自动存的日报"
2. **打开 Actions 页面** → 指着绿色对勾和时间戳说："这是它自己跑的记录"
3. **掏出手机打开微信** → 展示今天早上收到的推送："这就是成品"

> 顺序很重要：先给**证据**（仓库+日志），再给**结果**（微信）。老师最认这个。

## 六、一句话总结（收尾用）

> "说白了，我搭了一条**流水线**：闹钟叫我、采购员买料、AI 当编辑、快递员送上门。我做的事，是**设计这条流水线，并且规定编辑该写什么**。"
